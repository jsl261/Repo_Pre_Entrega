# Proyecto de Automatización QA - Sauce Demo

## Propósito del Proyecto
Este proyecto contiene una suite de pruebas automatizadas para el sitio web [Sauce Demo](https://www.saucedemo.com/). El objetivo principal es validar los flujos críticos (Smoke Test) de la aplicación, incluyendo el inicio de sesión exitoso, la correcta carga del inventario y el flujo de agregado de productos al carrito de compras, garantizando la calidad del software.

## Tecnologías Utilizadas
* **Lenguaje:** Python 3
* **Framework de Testing:** Pytest
* **Herramienta de Automatización:** Selenium WebDriver
* **Reportes:** Pytest-html
* **Control de Versiones:** Git y GitHub
